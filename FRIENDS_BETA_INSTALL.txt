cmd friends beta
================

This is a private test build from the developer, not an Apple-notarised public
release yet.

Why macOS may warn
------------------

cmd is currently ad-hoc signed because this beta was built without an
Apple Developer Program certificate. macOS may show a warning such as:

  "Apple could not verify cmd is free of malware."

That warning means Apple has not notarised this build. It does not mean the app
is doing anything hidden.

How to install
--------------

1. Drag cmd.app into Applications.
2. In Applications, right-click cmd.app and choose Open.
3. If macOS blocks it, open System Settings -> Privacy & Security and choose
   Open Anyway for cmd.
4. cmd will ask for Accessibility permission. Enable it in
   System Settings -> Privacy & Security -> Accessibility.
5. Quit and reopen cmd if the Cmd-V hold gesture does not start
   immediately after granting permission.

What the app does
-----------------

cmd watches your local clipboard so you can hold Cmd-V and pick a recent
copy from a cursor-origin register.

Privacy notes
-------------

- Clipboard history stays on this Mac.
- Sensitive entries are hidden in the HUD.
- You can exclude apps in cmd Settings -> Privacy.
- You can clear history from the menu bar.

Known beta limitation
---------------------

Because this build is not Apple-notarised, macOS may ask for manual approval.
A fully polished public release requires Apple Developer Program signing and
notarisation.
